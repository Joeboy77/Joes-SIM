# Contribute

Joe's SIM is open source, and students and teachers are welcome to help.

## Ways to help

- **Report a problem** or suggest an idea on
  [GitHub issues](https://github.com/Joeboy77/Joes-SIM/issues). Say what you did, what you
  expected and what happened.
- **Translate** the interface and lessons into French, Spanish, Portuguese, Arabic, Swahili or
  Twi. The translation files are in `apps/web/src/i18n/`.
- **Write challenges and lessons.** Challenges live in `packages/content`; every challenge needs
  a model solution that passes its tests, and tests check this automatically.
- **Improve the code.** Read the
  [contribution guide](https://github.com/Joeboy77/Joes-SIM/blob/main/CONTRIBUTING.md) first.

## Ground rules

- The engine must stay correct: changes need tests.
- No accounts and no tracking, ever, for the core product.
- Never copy another simulator's code, layout, graphics or text.
- Every feature must work with a keyboard and a screen reader.

Content you contribute is shared under CC BY 4.0, and code under the MIT licence.
