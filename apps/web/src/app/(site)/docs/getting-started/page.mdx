# Getting started

Joe's SIM runs entirely in your browser. There is nothing to install and no account to make.

## 1. Open the simulator

Go to the [simulator](/sim). It opens with a program that adds two numbers, and the inputs
3 and 4 already typed in.

## 2. Run it, then step through it

Press **Run** to see the answer, 7. Then press **Reset** and press **Step** to run one
instruction at a time, or **Micro** to see each register transfer. The **Explain** panel says
what just happened in plain words. The back buttons step backwards.

## 3. Change the program

Edit the code on the left. Mistakes are underlined as you type, with a suggestion. Your work
saves itself in this browser; the 📄 button lists your files.

## 4. Learn and practise

- [Lessons](/learn) explain the machine from the beginning, with live simulators.
- [Challenges](/challenges) are puzzles with tests, hints and scores.
- Turn on **predict mode** in the Explain panel to guess each step before it runs.

## 5. Go further

When the classic machine feels easy, Joe's SIM grows with you:

- **The extended machine.** In the simulator's settings, choose the **Extended** machine for a
  stack, subroutines, indirect and indexed addressing, interrupts and devices such as a keyboard and
  a pixel display. Every classic program still runs on it unchanged.
- **Pipelines and caches.** Choose the **Pipeline** or **Cache** view to see how the same run would
  time on a five-stage pipeline, or through a cache you configure.
- **Many cores.** The **Multicore** machine runs two to four Little Men on shared mailboxes, and
  shows races and the locks that prevent them.
- **The [compiler](/compiler)** turns a small high-level language into LMC, line by line.
- **[RISC-V](/riscv)** runs part of a real instruction set, laid out as in RARS.
- **The [machine designer](/machines)** lets you build your own machine from micro-operations,
  without writing code.

The [lessons](/learn) cover each of these with live examples.

## Keyboard shortcuts

Press **?** in the simulator for the full list: **P** runs or pauses, **S** steps, **Shift+S**
steps back, **M** micro-steps, **V** changes the view.
