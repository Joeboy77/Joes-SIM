# About Joe's SIM

Joe's SIM is a free, open-source simulator for learning how computers work at the machine
level. It starts with the Little Man Computer, a model designed by Stuart Madnick in 1965 to
teach exactly this, and grows towards real processor ideas: pipelines, caches, interrupts and
multiple cores.

It was built first for the students of DCIT 207, Computer Organisation and Architecture, and
for anyone else learning the same ideas.

## What it believes

- **See it to understand it.** Every step is animated, explained in plain words, and can be
  undone.
- **No accounts and no tracking.** Open the site and start. Your work stays on your device.
- **Works anywhere.** On a phone, offline, with a keyboard or a screen reader.
- **Open.** The code is MIT licensed and the lessons and challenges are CC BY 4.0, so teachers
  can adapt them.

Joe's SIM is built from the published Little Man Computer model. It does not copy code,
layout, graphics or text from any other simulator.

The source is on [GitHub](https://github.com/Joeboy77/Joes-SIM). See how to
[contribute](/contribute).
