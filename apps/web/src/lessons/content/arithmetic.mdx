`ADD name` adds a mailbox to the accumulator; `SUB name` subtracts it. The answer stays in the
accumulator. The <Highlight component="ALU">calculator</Highlight> does the work.

## Three digits only

Mailboxes and the accumulator hold three digits. If an answer does not fit, the thousands are
lost: 600 + 600 gives 200, not 1200. Try it by changing the inputs to `600, 600`.

## The negative flag

When a subtraction goes below zero, the Little Man raises a flag. Branch instructions look at
it, as you will see next lesson. Any instruction that puts a new value in the accumulator
clears it again.

<Note>
  Different textbooks and simulators disagree on negatives. Joe's SIM supports three **dialects**:
  Classic (000 to 999, with the flag), Higginson-compatible and OCR (both −999 to 999). Change the
  dialect in the simulator's settings and run the same subtraction to compare.
</Note>
