# Lessons

The lesson text in this folder is licensed under the Creative Commons Attribution 4.0
International licence (CC BY 4.0), like the rest of Joe's SIM's learning content. See
[packages/content/LICENSE](../../../../../packages/content/LICENSE).

Each lesson is an MDX file. Its title, length and prerequisites are listed in
[`../catalogue.ts`](../catalogue.ts), and its content is registered in [`index.ts`](index.ts).
Lessons can use `<LessonSim>`, `<Predict>`, `<Highlight>` and `<Note>`; see
[decision 0023](../../../../../docs/decisions/0023-lessons.md).
