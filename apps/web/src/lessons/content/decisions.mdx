So far every program has run straight down, one mailbox after another. **Branches** change
which instruction runs next by changing the <Highlight component="PC">program counter</Highlight>.

- `BRA name` always goes to `name`.
- `BRZ name` goes to `name` if the accumulator is **zero**.
- `BRP name` goes to `name` if the accumulator is **zero or positive** (the negative flag is
  clear).

If a `BRZ` or `BRP` does not branch, the program carries on to the next mailbox.

## Comparing two numbers

To compare a and b, subtract one from the other and test the answer.

<LessonSim
  title="The bigger one"
  view="flow"
  program={`

        STA a
        INP
        STA b
        SUB a
        BRP bbig
        LDA a
        OUT
        HLT
bbig    LDA b
        OUT
        HLT
a       DAT
b       DAT
`}
  inputs="3, 8"

/>

This simulator shows the **flow graph**: each box is a run of instructions with no branches,
and the arrows show where a branch can go. Run it twice, with `3, 8` and then `8, 3`, and watch
which path lights up.
