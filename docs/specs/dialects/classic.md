# Classic dialect

The Little Man Computer as commonly taught: three unsigned digits and a negative flag.
Dialect id: `classic`. Definition: `packages/engine/src/dialects/dialects.ts`.

Status key: **confirmed** means a public source states the rule. **Chosen** means the sources
leave it open (Wikipedia: "the actions of the accumulator … are not defined"), so Joe's SIM picked
the rule and records why. **Unconfirmed** means we believe it matches common practice but have no
source; it may change if one turns up.

| #   | Rule                                            | Value                                                                              | Status      | Source or reason                                                                                                                                                                                |
| --- | ----------------------------------------------- | ---------------------------------------------------------------------------------- | ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| C1  | Mailbox, accumulator and input range            | 000 to 999                                                                         | confirmed   | Wikipedia: mailboxes "can only hold values between 0 and 999"                                                                                                                                   |
| C2  | ADD result above 999                            | wraps modulo 1000 (999 + 1 = 000); the `alu` event marks it `wrapped`              | chosen      | Wikipedia: undefined. Wrapping is what a 3-digit counter does, and the wrap is shown to the learner                                                                                             |
| C3  | SUB result below zero                           | sets the negative flag; ACC holds the result modulo 1000 (4 − 9 = 995)             | chosen      | Wikipedia: "a negative flag will be set"; the value left in ACC is undefined. Modulo 1000 is the 3-digit wrap                                                                                   |
| C4  | Negative flag cleared by                        | any write to ACC that is not a SUB below zero (ADD, LDA, INP, SUB with result ≥ 0) | chosen      | Wikipedia ties the flag to "an underflow on SUBTRACT" only. Clearing it on the next ACC write keeps BRP meaning "the value in ACC is not negative"                                              |
| C5  | BRZ                                             | branches when ACC is 000 **and** the flag is clear                                 | confirmed   | Wikipedia: "Suggested behavior would be to branch if accumulator is zero and negative flag is not set". (With C1 to C3, ACC is never 000 with the flag set, so this only matters for fidelity.) |
| C6  | BRP                                             | branches when the flag is clear. Zero counts as positive                           | confirmed   | Wikipedia: BRP "depends solely on the negative flag"                                                                                                                                            |
| C7  | Spellings                                       | ADD SUB STA/STO LDA BRA BRZ BRP INP OUT HLT/COB DAT                                | confirmed   | Wikipedia lists COB ("coffee break") and STO as common alternatives                                                                                                                             |
| C8  | OTC (922)                                       | not available: assembling it is an error, running 922 is an invalid instruction    | chosen      | OTC is a Higginson extension, not in the original model                                                                                                                                         |
| C9  | 4xx, other 9xx, negative values                 | invalid instruction: the machine stops with an error                               | chosen      | Undefined in the original; stopping with an explanation teaches more than silently continuing                                                                                                   |
| C10 | 0xx with xx ≠ 00                                | halts (the address part is ignored)                                                | unconfirmed | Opcode 0 is HLT; most descriptions ignore the address                                                                                                                                           |
| C11 | PC after 99                                     | wraps to 00                                                                        | unconfirmed | The PC holds two digits                                                                                                                                                                         |
| C12 | Instruction with no address (for example `ADD`) | assembly error                                                                     | chosen      | Clearer for beginners than silently using 00                                                                                                                                                    |
| C13 | Labels                                          | case-sensitive                                                                     | chosen      | Matches Higginson, so programs move between dialects unchanged                                                                                                                                  |

Reference programs that show the differences from the signed dialects: `subtract`
(4 − 9 outputs 995) and `sign-test`.
