# Higginson-compatible dialect

Matches the behaviour of Peter Higginson's online LMC simulator
(<https://peterhigginson.co.uk/lmc/>), implemented from its public help page and observed
behaviour, **not** its code. Dialect id: `higginson`.

Status key as in [classic.md](classic.md).

| #   | Rule                                       | Value                                                                                                                 | Status           | Source or reason                                                                                                      |
| --- | ------------------------------------------ | --------------------------------------------------------------------------------------------------------------------- | ---------------- | --------------------------------------------------------------------------------------------------------------------- |
| H1  | Accumulator range                          | -999 to 999                                                                                                           | confirmed        | Help page: the accumulator holds "3 digits and a sign (-999 to 999)"                                                  |
| H2  | Mailbox and input range                    | -999 to 999                                                                                                           | unconfirmed      | The help page does not say. Storing ACC with STA must not lose the sign, so mailboxes take the same range             |
| H3  | SUB below zero                             | ACC holds the true negative result (4 − 9 = −5)                                                                       | confirmed        | Follows from H1                                                                                                       |
| H4  | Result beyond ±999                         | wraps modulo 1000 keeping the sign (999 + 1 = 0, −999 − 1 = 0, −999 − 999 = −998); the `alu` event marks it `wrapped` | unconfirmed      | Not stated on the help page. Chosen to match the Classic wrap so the same programs behave the same way                |
| H5  | Negative flag                              | set exactly when ACC is below zero, after every write to ACC                                                          | unconfirmed      | The help page does not mention a flag; with a signed accumulator BRP "zero or positive" is the same as "not negative" |
| H6  | BRZ                                        | branches when ACC is 0                                                                                                | confirmed        | Help page: "branches … if the Accumulator is zero"                                                                    |
| H7  | BRP                                        | branches when ACC is zero or positive                                                                                 | confirmed        | Help page: "zero or positive"                                                                                         |
| H8  | Spellings                                  | ADD SUB STA/STO LDA BRA BRZ BRP INP OUT OTC HLT DAT                                                                   | confirmed        | Help page lists "STA or STO" and OTC                                                                                  |
| H9  | COB                                        | not accepted                                                                                                          | chosen           | Not on the help page; the error suggests HLT                                                                          |
| H10 | OTC (922)                                  | outputs ACC as a character code (10 = new line)                                                                       | confirmed        | Help page: "Output accumulator as a character if address is 22"; "10 for newline"                                     |
| H11 | 4xx                                        | invalid instruction error                                                                                             | confirmed        | Help page: "This code is unused and gives an error"                                                                   |
| H12 | Other 9xx, negative values as instructions | invalid instruction error                                                                                             | unconfirmed      | Not stated                                                                                                            |
| H13 | 0xx with xx ≠ 00                           | halts                                                                                                                 | unconfirmed      | Not stated                                                                                                            |
| H14 | PC after 99                                | wraps to 00                                                                                                           | unconfirmed      | Help page: PC "holds only 2 digits (0 to 99)"; wrapping is not stated                                                 |
| H15 | Instruction with no address                | assembles with address 00, with a warning                                                                             | confirmed        | Help page: "Omitting an address normally assembles as 0"                                                              |
| H16 | Labels                                     | case-sensitive                                                                                                        | confirmed        | Help page: "Loop and loop are different labels"                                                                       |
| H17 | Comments                                   | `//`, plus `;` and `#`                                                                                                | partly confirmed | `//` is on the help page; `;` and `#` are Joe's SIM additions, accepted in all dialects                               |

Not reproduced, on purpose: the help page says leaving out an address and then adding a comment
gives an error. Joe's SIM never lets a comment change how a line is read.
