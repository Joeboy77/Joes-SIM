# Specifications

Instruction set and dialect specifications. Every rule names its source; rules that cannot be
confirmed from a public source are marked **unconfirmed** and reviewed before use.

Planned files:

- `classic.md`: the classic Little Man Computer (Phase 1)
- `dialects/`: one file per dialect, listing every edge-case rule (Phase 1)
- `extended.md`: the extended machine, reviewed before building (Phase 6)
- `little-language.md`: the Little Language grammar (Phase 9)
