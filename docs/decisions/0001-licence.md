# 0001: Licence

## Context

The brief (Section 13) leaves the code licence open: MIT or GPL-3.0. Content licence suggested as CC BY 4.0.

## Options

- MIT: simplest and most permissive.
- GPL-3.0: derived versions must stay open.

## Choice

MIT for code. CC BY 4.0 for lessons, challenges and teacher packs in `packages/content`.

## Reason

Chosen by the project owner on 2026-10-29. MIT makes it easiest for schools, LMS platforms and
other projects to embed and reuse the simulator, which helps it reach more learners.
